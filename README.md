# Lumzo

Lumzo is a high-performance, lightweight multi-YouTube viewer and monitoring dashboard.

## Features
- **Flexible Grid Views**: Solo (1x), Duo (2x), Grid (3x), Wall (4x), and Mega (5x) grid layouts.
- **Thumbnail Facades**: Click-to-load facades keep RAM usage minimal for up to 30 players.
- **YouTube Shorts Support**: Auto-detects Shorts URLs with uniform 16:9 pillarboxing.
- **Global Playback Controls**: Play, Pause, Mute, and Unmute across all loaded players.
- **Keyboard Shortcuts**: `Space` (Play/Pause), `M` (Mute/Unmute), `F` or `/` (Search focus).
- **Drag & Drop Reordering**: Drag cards around the grid to resequence your wall position.
- **Shareable State URLs**: Encode video walls directly into share links (`?cols=3&v=ID1,ID2`).
- **LocalStorage Auto-Save**: Preserves active video walls automatically upon browser refresh.
- **Ad & Monetization Ready**: Pre-styled ad containers and legal pages (`privacy.html` and `terms.html`).

## Deployment
Static HTML/CSS/JS hosted directly via **GitHub Pages**.
